# licence_ecunexo

Plataforma de licenciamiento EcuNexo: API de emisión (`ecunexo_license_api`) y panel de operadores (`ecunexo_license`).

Host y base de datos separados del producto cliente. Versión actual: ver archivo `VERSION`.

```
ecunexo_license_api/   # API .NET — puerto 5090, BD licensing_ecunexo
ecunexo_license/       # SPA operadores (Vite)
nuget-local/           # Feed local EcuNexo.Core
```
